# ייצוא רישומים לגיליון גוגל ספציפי

## הבעיה
כרגע אפשר לייצא רישומים רק לקובץ אקסל מקומי (`exportToExcel` ב-`components/AdminTable.jsx`). יש צורך לייצא את אותם נתונים גם לגיליון Google Sheets ספציפי וקבוע, כדי שגורמים נוספים (רכזת/הנהלה) יוכלו לצפות בתמונת מצב עדכנית בלי לפתוח את מסך הניהול.

הפרויקט כבר כולל חיבור ל-Google Sheets דרך Service Account (`lib/googleSheets.js`, `appendRegistrationRow`) שמשמש להוספת שורה בכל הרשמה חדשה, לגיליון אחר (`GOOGLE_SHEET_ID`). הגיליון הנדרש כאן הוא גיליון **נפרד**.

## פתרון

### הגדרות סביבה (בוצע)
- `GOOGLE_SERVICE_ACCOUNT_EMAIL` / `GOOGLE_SERVICE_ACCOUNT_PRIVATE_KEY` — כבר מולאו עם Service Account ייעודי (`sheets-export@kunspr.iam.gserviceaccount.com`), משותף כעורך על הגיליון היעד.
- `GOOGLE_EXPORT_SHEET_ID` — משתנה סביבה חדש, מצביע על הגיליון הספציפי (נפרד מ-`GOOGLE_SHEET_ID` הקיים).

### lib/googleSheets.js
פונקציה חדשה, למשל `replaceExportSheet({ headers, rows })`:
- מתחברת לגיליון לפי `GOOGLE_EXPORT_SHEET_ID` עם אותו Service Account הקיים.
- מוחקת את כל התוכן הקיים בגיליון (`sheet.clear()`).
- כותבת שורת כותרות ואז את כל שורות הנתונים.
- כל קריאה **מחליפה לחלוטין** את תוכן הגיליון (לא append) — מבטיח שהגיליון תמיד משקף בדיוק את מה שסונן בטבלה בזמן הלחיצה.

### API route חדש
`app/api/registrations/export-to-sheet/route.js` (POST):
- מקבל בגוף הבקשה `{ headers, rows }` (אותה צורת נתונים שכבר מחושבת לייצוא אקסל).
- קורא ל-`replaceExportSheet`.
- מחזיר הצלחה/שגיאה כ-JSON.
- רץ אך ורק בצד שרת — המפתח הסודי לא נחשף לדפדפן.

### components/AdminTable.jsx
- כפתור חדש "ייצוא לגיליון גוגל", מיד ליד כפתור "ייצוא לאקסל" הקיים.
- פונקציה `exportToGoogleSheet(rows)` — מחשבת headers+dataRows באותה לוגיקה בדיוק כמו `exportToExcel` (13 עמודות: תאריך, תלמיד/ה, הורה, טלפון, אימייל, סוג, כלים, סטטוס, תשלום, מורה, יום, שעה, הערות), שולחת POST ל-API החדש.
- בזמן הייצוא: הכפתור מציג "מייצא..." ונחסם ללחיצה חוזרת.
- בסיום: הודעת הצלחה או שגיאה גלויה למשתמש (בניגוד לסנכרון האוטומטי השקט הקיים ב-`appendRegistrationRow` — כאן זו פעולה יזומה של המשתמש, ולכן כשלון חייב להיות גלוי).
- הכפתור מייצא את `filtered` (אותן שורות שמיוצאות היום לאקסל) — כיבוד הסינון הפעיל במסך.

## מחוץ לתחום
- לא נוגעים בייצוא האקסל הקיים (`exportToExcel`) או בהדפסה (`printTable`).
- לא נוגעים בסנכרון ההרשמות האוטומטי הקיים (`appendRegistrationRow`, `GOOGLE_SHEET_ID`) — נשאר בדיוק כפי שהוא.
- אין סנכרון אוטומטי/רציף לגיליון החדש — רק ייצוא ידני בלחיצת כפתור.
- אין היסטוריית גרסאות/גיבוי של תוכן הגיליון לפני מחיקה — כל ייצוא מוחק את הקיים ללא שחזור.

## בדיקות
- טסט ל-`replaceExportSheet` (עם מוק ל-`GoogleSpreadsheet`) שבודק שהפונקציה מנקה את הגיליון וכותבת כותרות + שורות כצפוי.
- טסט ל-API route שבודק תגובת הצלחה/שגיאה בהתאם לתוצאת `replaceExportSheet`.
