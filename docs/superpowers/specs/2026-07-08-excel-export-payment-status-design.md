# עמודת תשלום בייצוא לאקסל

## הבעיה
ייצוא הרישומים לאקסל (`exportToExcel` ב-`components/AdminTable.jsx`) לא כולל את סטטוס התשלום (`registration_status`), למרות שהוא מוצג בטבלה במסך הניהול דרך `RegistrationStatusBadge`.

## פתרון
1. לחלץ מיפוי סטטוס תשלום → תווית עברית משותף (במקום השכפול הקיים ב-`RegistrationStatusBadge`):
   - `Confirmed` → `שולם`
   - `Pending` (או ערך אחר/ריק) → `ממתין`
   - `Cancelled` → `בוטל`
2. להוסיף עמודת `תשלום` למערך ה-`headers` וה-`dataRows` ב-`exportToExcel`, מיד אחרי `סטטוס` ולפני `מורה` — תואם לסדר העמודות בטבלה במסך.
3. `RegistrationStatusBadge` ישתמש באותה פונקציית מיפוי כדי למנוע כפילות.

## מחוץ לתחום
- לא נוגעים בעמודת "הערות" (admin_notes), שם ממשיכה להופיע ההערה "נרשם ומתכנן לשלם במזומן" כפי שהיא היום.
- לא משנים את ערכי `registration_status` עצמם או את זרימת התשלום.
- לא נוגעים בטבלת ה-`printTable` (הדפסה) — לא התבקש.

## בדיקות
- טסט קיים/חדש שבודק ש-`exportToExcel` (או פונקציית המיפוי) מחזירה את התווית הנכונה עבור כל אחד משלושת הערכים ועבור ערך ריק/undefined.
