# Excel Export Day Colors Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Make the admin registrations table's "ייצוא Excel" button produce a real `.xlsx` file with each row's background colored by registration day, so consecutive same-day rows are visually grouped.

**Architecture:** A new `lib/excelExport.js` module holds two pure/isolated pieces: `assignRowColors(rows)` (pure function, unit-tested) that walks the already-date-sorted rows and returns one background color per row, cycling through a 6-color palette every time the day changes; and `downloadExcelFile(...)` which dynamically imports `exceljs`, builds a styled workbook from header/row/color arrays, and triggers a browser download. `components/AdminTable.jsx` is updated to build the same column data it already builds for CSV, but hand it to the new module instead of `exportToCSV`.

**Tech Stack:** Next.js 14 client component, `exceljs` (new dependency) for `.xlsx` generation in the browser, Jest (`next/jest`, `testEnvironment: 'node'`) for unit tests.

## Global Constraints

- Do not change the CSV-only `printTable` function or any other export/print path — only the "ייצוא Excel" button's behavior changes.
- Keep the exact same columns, order, and cell values as the current CSV export: `תאריך, תלמיד/ה, הורה, טלפון, אימייל, סוג, כלים, סטטוס, מורה, יום, שעה, הערות`.
- Downloaded filename format stays `רישומים_DD-MM-YYYY.xlsx` (same date formatting as today, extension changes from `.csv` to `.xlsx`).
- Palette is exactly 6 light colors, cycling with modulo — do not add day-count-dependent logic.
- `assignRowColors` must be a pure function with no dependency on `exceljs`, the DOM, or Next.js — it must be testable under `testEnvironment: 'node'`.

export const DAY_COLOR_PALETTE = [
  'FFFFFFFF', // white
  'FFE8F0FE', // light blue
  'FFE6F4EA', // light green
  'FFFFF4E5', // light orange
  'FFF3E8FD', // light purple
  'FFFCE8E6', // light pink
];

function dayKey(createdAt) {
  if (!createdAt) return '';
  const date = new Date(createdAt);
  if (isNaN(date.getTime())) return String(createdAt);
  return `${date.getFullYear()}-${date.getMonth()}-${date.getDate()}`;
}

export function assignRowColors(rows) {
  const colors = [];
  let colorIndex = 0;
  let prevKey = null;
  for (const row of rows) {
    const key = dayKey(row.created_at);
    if (prevKey !== null && key !== prevKey) {
      colorIndex = (colorIndex + 1) % DAY_COLOR_PALETTE.length;
    }
    colors.push(DAY_COLOR_PALETTE[colorIndex]);
    prevKey = key;
  }
  return colors;
}
```

export async function downloadExcelFile({ sheetName, headers, rows, rowColors, filename }) {
  const ExcelJS = (await import('exceljs')).default;
  const workbook = new ExcelJS.Workbook();
  const sheet = workbook.addWorksheet(sheetName, { views: [{ rightToLeft: true }] });

  sheet.addRow(headers);
  sheet.getRow(1).font = { bold: true };

  rows.forEach((rowValues, i) => {
    const row = sheet.addRow(rowValues);
    const color = rowColors[i];
    if (!color) return;
    for (let col = 1; col <= headers.length; col++) {
      row.getCell(col).fill = { type: 'pattern', pattern: 'solid', fgColor: { argb: color } };
    }
  });

  const buffer = await workbook.xlsx.writeBuffer();
  const blob = new Blob([buffer], {
    type: 'application/vnd.openxmlformats-officedocument.spreadsheetml.sheet',
  });
  const url = URL.createObjectURL(blob);
  const a = document.createElement('a');
  a.href = url;
  a.download = filename;
  a.click();
  URL.revokeObjectURL(url);
}
```

It is verified manually in Task 4.

async function exportToExcel(rows) {
  const headers = ['תאריך', 'תלמיד/ה', 'הורה', 'טלפון', 'אימייל', 'סוג', 'כלים', 'סטטוס', 'מורה', 'יום', 'שעה', 'הערות'];
  const dataRows = rows.map(r => [
    new Date(r.created_at).toLocaleDateString('he-IL'),
    r.student_name || '',
    r.parent_name || '',
    r.parent_phone || '',
    r.parent_email || '',
    getTypeLabel(r),
    Array.isArray(r.instruments)
      ? (r.instruments.length > 0 ? r.instruments.join('; ') : (r.selected_course || ''))
      : (r.instruments || r.selected_course || ''),
    r.status || '',
    r.teacher || '',
    r.assigned_day != null && r.assigned_day !== '' ? (DAY_NAMES[Number(r.assigned_day)] ?? r.assigned_day) : '',
    r.assigned_time ? r.assigned_time.slice(0, 5) : '',
    r.admin_notes || '',
  ]);
  const rowColors = assignRowColors(rows);
  const filename = `רישומים_${new Date().toLocaleDateString('he-IL').replace(/\//g, '-')}.xlsx`;
  await downloadExcelFile({ sheetName: 'רישומים', headers, rows: dataRows, rowColors, filename });
}
